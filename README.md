# sendtoher

เว็บส่งไฟล์ส่วนตัวที่ทำงานแบบเดียวกับ Send Anywhere ใช้รหัส 4 หลัก ไม่มีโฆษณา ไม่ต้องสมัคร ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ต้องมีแค่ Node.js 18 ขึ้นไป

## ทำงานยังไง
| โหมด | กดปุ่ม | ไฟล์วิ่งทางไหน | ข้อดี / ข้อจำกัด |
|---|---|---|---|
| **ส่งตรง (P2P)** | **Send Files** | จากเบราว์เซอร์ผู้ส่งไปผู้รับโดยตรงผ่าน WebRTC ไม่ผ่านเซิร์ฟเวอร์ | เร็วที่สุด ไม่ต้องรออัปโหลดก่อน แต่ทั้งสองฝั่งต้องเปิดหน้าเว็บค้างไว้ |
| **ผ่านเซิร์ฟเวอร์ (relay)** | (สลับให้อัตโนมัติ) | ผู้ส่ง → เซิร์ฟเวอร์ → ผู้รับ แบบไหลต่อเนื่อง ไม่พักไฟล์ลงดิสก์ | ใช้เมื่อต่อตรงไม่ได้ภายใน 10 วินาที เช่นเน็ตมือถือบางค่าย |
| **ลิงก์** | **or upload as a link…** | อัปโหลดมาพักไว้บนเซิร์ฟเวอร์ก่อน | ผู้รับมาโหลดทีหลังได้ ผู้ส่งปิดเว็บได้ |

เซิร์ฟเวอร์ทำหน้าที่จับคู่สองเบราว์เซอร์ด้วยรหัส 4 หลัก (ผ่าน Server-Sent Events) แล้วให้ทั้งสองฝั่งคุยกันโดยตรง

ไฟล์ที่ใหญ่กว่า 512 MB: Chrome หรือ Edge บนคอมจะถามให้เลือกโฟลเดอร์ แล้วเขียนไฟล์ลงดิสก์โดยตรง ไม่กินแรม ส่วนเบราว์เซอร์อื่นที่ได้ไฟล์ใหญ่กว่า 1.5 GB จะสลับไปส่งผ่านเซิร์ฟเวอร์ให้อัตโนมัติ

## รันบนเครื่อง
```bash
node server.js
# เปิด http://localhost:8080
```

## ตั้งค่า (ตัวแปรสภาพแวดล้อม)
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | 8080 | พอร์ต |
| `SITE_KEY` | (ว่าง) | ต้องใส่รหัสนี้ถึงจะ **ส่ง** ได้ ฝั่งรับไม่ต้องใส่ แนะนำให้ตั้งเมื่อเปิดบนอินเทอร์เน็ต |
| `STUN_URLS` | Google + Cloudflare STUN | เซิร์ฟเวอร์ STUN ที่ใช้ช่วยให้ต่อตรงได้ |
| `TURN_URL` `TURN_USER` `TURN_PASS` | (ว่าง) | ไม่จำเป็น เพราะมี relay ในตัวแล้ว ใส่ถ้ามี coturn ของตัวเอง |
| `MAX_MB` | 4096 | โหมดลิงก์: ขนาดรวมสูงสุดต่อรหัส |
| `MAX_TTL_MIN` | 60 | อายุรหัสสูงสุด (นาที) |
| `DATA_DIR` | ./data | โหมดลิงก์: โฟลเดอร์เก็บไฟล์ชั่วคราว |
| `TRUST_PROXY` | 0 | ตั้งเป็น `1` เมื่ออยู่หลัง Caddy/Nginx |

อายุรหัส (10 นาที) และการลบไฟล์หลังโหลดในโหมดลิงก์ ตั้งค่าได้ที่ `TTL_MIN` กับ `ONE_TIME` ในส่วน `<script>` ของ `public/index.html`

## เปิดใช้บนอินเทอร์เน็ต
**ต้องมี HTTPS** ไม่งั้นมือถือจะไม่ยอมใช้ WebRTC

```bash
docker build -t sendtoher .
docker run -d --restart unless-stopped -p 8080:8080 -e SITE_KEY=รหัสลับ -e TRUST_PROXY=1 sendtoher
```
Caddy (ทำ HTTPS ให้อัตโนมัติ):
```
send.example.com {
    reverse_proxy localhost:8080 {
        flush_interval -1
    }
}
```
ถ้าใช้ Nginx ต้องตั้งค่า `proxy_buffering off; proxy_request_buffering off; client_max_body_size 0; proxy_read_timeout 1h;`

เซิร์ฟเวอร์ควรอยู่ใกล้ผู้ใช้ (สิงคโปร์หรือไทย) เพื่อให้โหมด relay และโหมดลิงก์เร็ว ส่วนโหมดส่งตรงจะเร็วเท่ากันไม่ว่าเซิร์ฟเวอร์อยู่ที่ไหน

## ความปลอดภัย
- ข้อมูลในโหมดส่งตรงถูกเข้ารหัสด้วย DTLS ของ WebRTC เสมอ
- เดารหัสผิดได้ 8 ครั้งต่อ IP ต่อ 15 นาที และรับไฟล์ได้ทีละคนต่อรหัส
- รหัส 4 หลักมีแค่ 10,000 แบบ ถ้าจะส่งไฟล์ลับมาก ให้บีบอัดเป็น zip แล้วใส่รหัสผ่านก่อนส่ง
